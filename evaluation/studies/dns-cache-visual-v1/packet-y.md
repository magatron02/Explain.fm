# คำอธิบายเรื่องโพสต์อิทของระบบ

ลองนึกว่าระบบจดคำตอบเรื่องที่อยู่เว็บไซต์ไว้บนโพสต์อิท ครั้งแรกที่ยังไม่มีโพสต์อิทใช้ได้ ระบบต้องไปขอคำตอบจากแหล่งข้อมูล

โพสต์อิทแต่ละใบมีเวลา ทีทีแอล กำกับอยู่ ซึ่งจำกัดว่านำคำตอบบนใบนั้นกลับมาใช้ได้นานแค่ไหน

ถ้ามีคำถามเดิมก่อน ทีทีแอล หมด ระบบอาจอ่านคำตอบจากโพสต์อิทได้ จึงไม่ต้องถามแหล่งข้อมูลใหม่ทุกครั้ง

เมื่อ ทีทีแอล หมด ระบบไม่ควรใช้โพสต์อิทใบเดิมต่อ แต่ต้องปรึกษาแหล่งข้อมูลอีกครั้ง ทีทีแอล จึงเป็นขอบเขตเวลาในการใช้ซ้ำ ไม่ใช่ตราประทับว่าคำตอบถูกต้องเสมอ

โพสต์อิทเป็นเพียงภาพเปรียบเทียบ ไม่ได้หมายความว่าระบบ DNS เก็บข้อมูลบนกระดาษจริง
