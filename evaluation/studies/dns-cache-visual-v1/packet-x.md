# คำอธิบายเรื่องคำตอบที่จำไว้

ครั้งแรกที่ระบบค้นหาชื่อเว็บไซต์ ถ้ายังไม่มีคำตอบที่ใช้ซ้ำได้ ระบบต้องไปขอคำตอบจากแหล่งข้อมูล

เมื่อได้คำตอบแล้ว ระบบเก็บคำตอบนั้นไว้พร้อมเวลา ทีทีแอล ซึ่งจำกัดว่านำคำตอบกลับมาใช้ได้นานแค่ไหน

ถ้ามีคำถามเดิมก่อน ทีทีแอล หมด ระบบอาจใช้คำตอบที่เก็บไว้ได้ จึงไม่ต้องถามแหล่งข้อมูลใหม่ทุกครั้ง

เมื่อ ทีทีแอล หมด ระบบไม่ควรนำคำตอบเดิมกลับมาใช้ต่อ แต่ต้องปรึกษาแหล่งข้อมูลอีกครั้ง ทีทีแอล จึงเป็นขอบเขตเวลาในการใช้ซ้ำ ไม่ใช่หลักฐานว่าคำตอบถูกต้องเสมอ
