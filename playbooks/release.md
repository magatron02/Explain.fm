# Playbook: Release

1. Define the included artifact versions and release boundary.
2. Run deterministic checks and required quality evaluations.
3. Confirm constitutional gates, provenance, privacy, and rollback readiness.
4. Review known limitations and partial capabilities for accurate communication.
5. Package versioned configuration, prompts, models, and schema references where applicable.
6. Release incrementally and observe stage failures and quality signals.
7. Record outcomes, regressions, and evidence for the next decision.

No release is complete while required evaluation evidence is missing.
