# Playbook: New Agent

1. Prove that a distinct responsibility cannot remain inside an existing role or deterministic step.
2. Define goal, inputs, outputs, prohibited behavior, and failure behavior in a blueprint and contract.
3. Keep the role separate from adjacent retrieval, reasoning, storytelling, voice, and evaluation concerns.
4. Specify provenance, observability, versioning, and human-review requirements.
5. Build the narrowest evaluated task before granting broader tools or autonomy.
6. Add regression cases for fabrication, scope drift, and silent failure.

Do not add an agent solely to mirror an organizational title or speculative scale.
