# Playbook: Query Knowledge

1. Start at `knowledge/index.md` and identify relevant reviewed topics and source notes.
2. Search accepted sources with `packages/research/search.py`; follow relevant `[[wikilinks]]`.
3. Use `packages/research/evidence_pack.py` for exact `file:line` evidence.
4. Consult `knowledge/raw/` only when reviewed material cannot answer the question.
5. Separate supported facts, interpretation, disagreement, and missing evidence.
6. Save valuable synthesis only as a reviewed research brief; never silently write generated answers back as established knowledge.

Return an explicit evidence gap when the vault cannot support an answer.
