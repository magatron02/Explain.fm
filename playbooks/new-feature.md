# Playbook: New Feature

1. Identify the listener problem and which first principle the feature advances.
2. Confirm the work belongs to the active roadmap era.
3. Define a measurable outcome, boundary, and explicit non-goals.
4. Check affected contracts, constitution rules, privacy, and provenance flow.
5. Propose the smallest end-to-end slice; use an RFC or ADR when the change is durable or cross-cutting.
6. Implement with boundary tests and evaluation evidence.
7. Update documentation and record verified lessons or patterns.

Reject or park work that cannot show an improvement to understanding, retention, accessibility, or enjoyment.
