# Obsidian Internal Links Documentation

## Why this source matters

Explain.fm connects source notes, topics, examples, and mental models with Obsidian links. The official link behavior defines what remains navigable inside the vault and what remains portable Markdown.

## Scope

Internal link formats, file rename behavior, heading links, block links, and interoperability limits.

## Key claims and evidence

| Claim | Evidence or location | Confidence |
| --- | --- | --- |
| Internal links connect notes into a knowledge network. | Introduction | High |
| Obsidian supports Wikilink and Markdown internal-link formats. | “Supported formats for internal links” | High |
| Obsidian can update internal links when a linked file is renamed. | Introduction | High |
| Links can target a note, heading, or identified block. | “Link to a file”, “Link to a heading”, and “Link to a block” | High |
| Obsidian block references are not standard Markdown and do not work outside Obsidian. | “Interoperability” warning | High |
