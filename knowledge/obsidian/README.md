# Obsidian Knowledge

The repository root is opened locally as the Explain.fm Obsidian vault. Store curated, human-readable knowledge notes in this directory so they remain separate from raw sources and application code.

## Note requirements

- Preserve source links and provenance.
- Separate sourced facts from interpretation.
- Prefer one primary concept per note.
- Use explicit links between related concepts.
- Do not copy raw HTML, ads, navigation, duplicate content, or extraction noise.

Local Obsidian settings and workspace state live in `.obsidian/` and are intentionally excluded from Git.
