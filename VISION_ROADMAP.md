# Vision Roadmap

This document contains long-term ideas only. These are not active implementation tasks, commitments, or approved roadmap items. Promotion into `ROADMAP.md` requires evidence, an explicit decision, and a bounded delivery plan.

## Long-term possibilities

- Explanations that adapt to a listener's existing mental models.
- Multi-language episodes that preserve meaning, tone, and source traceability.
- Expert and institution publishing with transparent editorial provenance.
- Connected learning journeys across episodes and disciplines.
- Listener questions that improve future editions without turning the product into a chatbot.
- Open interfaces for trusted knowledge collections and evaluation suites.
