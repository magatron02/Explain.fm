# Memory Policy

Memory exists to improve continuity, connections, and future explanations.

## Store

- Concepts
- Relationships
- Insights supported by evidence
- Mental models
- Listener preferences explicitly provided or safely derived with consent
- Episode history and relevant evaluation outcomes

## Do not store

- Raw HTML
- Ads
- Cookie banners
- Duplicated text
- Navigation menus
- Irrelevant metadata

Every stored item should retain provenance, scope, and confidence where relevant. Memory must not convert uncertain inference into fact. Corrected or superseded knowledge must remain auditable, and listener memory must be isolated and removable.
