# Naming Standard

- Use precise domain language from `DOMAIN_MODEL.md`.
- Name artifacts for their responsibility, not their implementation technology.
- Use lowercase kebab-case for directories and Markdown filenames except established root operating documents.
- Use numbered prefixes for ordered blueprints and ADR identifiers.
- Avoid vague names such as `helper`, `manager`, `misc`, or `data` when a domain term exists.
- Preserve stable identifiers across pipeline stages; do not overload one identifier for different artifacts.
