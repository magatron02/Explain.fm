# Blueprint 002: Memory

## Goal

Preserve useful concepts and connections so later research and episodes gain continuity without retaining source noise.

## Responsibilities

- Store approved memory categories from `MEMORY_POLICY.md`.
- Preserve provenance, confidence, scope, and revision history.
- Retrieve relevant context without presenting inference as fact.
- isolate and support removal of listener-specific memory.

## Inputs

Curated concepts, relationships, insights, mental models, episode history, listener preferences, and evaluation outcomes.

## Outputs

Relevant, attributable memory context plus confidence and provenance metadata.

## Dependencies

Memory policy, cleaned knowledge, identity boundaries, and evaluation feedback.

## Failure Cases

Noise accumulation, duplication, stale facts, cross-listener leakage, unsupported relationships, or irrelevant retrieval.

## Future Ideas

Temporal knowledge, contradiction tracking, explainable graph traversal, and listener-controlled memory views.
