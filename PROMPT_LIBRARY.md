# Prompt Library

This document catalogs future prompt families. It does not contain production prompts or define a prompt execution system.

| Area | Intended responsibility | Location |
| --- | --- | --- |
| Research | Evidence gathering, claim support, uncertainty | `prompts/research/` |
| Planner | Teaching sequence and story structure | `prompts/planner/` |
| Writer | Natural, evidence-bound dialogue | `prompts/writer/` |
| QA | Factual, structural, and constitutional review | `prompts/qa/` |
| Voice | Speech preparation and delivery constraints | `prompts/voice/` |

Future prompts must declare their input contract, expected output, prohibited behavior, version, and evaluation evidence. Prompt text should not become a substitute for module contracts.
