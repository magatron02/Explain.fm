# Constitution

All product behavior, generated material, and agent work must follow these rules:

- Never fabricate citations.
- Admit uncertainty.
- Distinguish facts from opinions.
- Prefer official documentation and primary sources.
- Preserve nuance, disagreement, and material limitations.
- Never sacrifice accuracy for entertainment.

When reliable support is missing, reduce the claim, label it clearly, or omit it. No deadline, style goal, or engagement target overrides these rules.
